### Установка на Android

1. Откройте ссылку выше на Android-телефоне (или отсканируйте QR-код на странице сборки Expo).
2. Нажмите **Install** / скачайте файл `.apk`.
3. Если Android блокирует установку, разрешите установку из этого источника:
   - **Настройки → Безопасность** (или **Приложения**) → включите **Установку неизвестных приложений** для браузера / Файлов.
4. Откройте скачанный APK и подтвердите установку.
5. Запустите **AddMobileApp** из списка приложений.

> Это внутренняя preview-сборка (не из Google Play). При переустановке может снова понадобиться разрешение на «неизвестные источники».

## Настройка для разработки

### Требования

- Node.js 18+
- npm
- Expo Go (опционально, для просмотра на устройстве) или Android-эмулятор

### Установка зависимостей

```bash
npm install
```

### Запуск проекта

```bash
npm start
```

Далее:

- нажмите `a` для Android-эмулятора
- нажмите `w` для web
- отсканируйте QR-код в **Expo Go** на физическом устройстве (одна Wi‑Fi сеть; VPN лучше отключить)

### Собрать новый APK

```bash
npm run build:apk
```

Нужен аккаунт Expo и вход в EAS CLI (`npx eas-cli login`).
